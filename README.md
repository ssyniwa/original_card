# original_card
🃏 属性トランプ・AIカードバトル (Attribute Trump AI Battle)
PythonとStreamlitを使用して作成した、AIと対戦できるオリジナルの属性トランプカードバトルゲームです。
火・水・雷・風の4属性に分かれた美しいカードを駆使し、ペアやフラッシュなどの「コンボ」を組み合わせて強力なAIを倒そう！  
🌟 主な特徴
4つの属性システム: 火（🔥）・水（💧）・雷（⚡）・風（🌪️）の属性を持つカードが登場。  
多彩な役（コンボ）: ペア、スリーカード、フォーカード、フラッシュ、ストレートフラッシュなどの役を判定し、役に応じた倍率でダメージが変動。  
賢いAI対戦相手: AIは手札の中から最適なコンボを自動で計算して攻撃してきます。  
無限に遊べる山札システム: デッキがなくなっても自動でリシャッフルされるため、途切れることなくバトルを楽しめます。  
🛠️ 使用技術
Python  
Streamlit (WebアプリケーションのUI構築)  
itertools (AIの最適なコンボの組み合わせ探索)  
🚀 遊び方 / 実行方法
1.リポジトリのクローンまたはファイルの準備
本プログラムのスクリプト（例: app.py）と、カード画像を入れる images/ フォルダを同じ階層に配置します。
2.ライブラリのインストール
Streamlitがインストールされていない場合は、事前にインストールしてください。
pip install streamlit
3.アプリケーションの起動ターミナル（コマンドプロンプト）で以下のコマンドを実行します。
streamlit run app.py
4.ゲームスタート
ブラウザが自動で立ち上がり、ゲーム画面が表示されます。手札から好きなカードを選んで「選択したカードで攻撃！」ボタンを押しましょう！
